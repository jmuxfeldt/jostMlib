## jostMlib

A Quark Library for the SuperCollider Programming Language.

The menus work nearly identically to html popup menus. 

Visually best with in combination with the [wslib](https://github.com/supercollider-quarks/wslib) quark. 

### ActionMenu
Closes on click outside or on escape.

![ActionMenu](./ActionMenu.jpg)

### PathActionMenu
Directories navigate to the next level with a new window and an up ../ option.

Closes on click outside or on escape.
